# Calculadora en lenguaje C usando librerías personalizadas

## Descripción del proyecto

Este proyecto consiste en una calculadora básica desarrollada en lenguaje C.  
El programa permite realizar operaciones matemáticas como suma, resta, multiplicación y división.

El objetivo principal del proyecto es practicar el uso de archivos separados en C, utilizando una librería personalizada para organizar mejor las funciones del programa.
